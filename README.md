# Посмотри в окно 🪟

Интерактивный веб-сервис, который подбирает прямые трансляции из разных городов по запросу
пользователя и помогает сменить обстановку, не выходя из дома.

## Ключевая функциональность

- 🚀 Подбор видео по городу и времени суток через форму поиска
- 💡 Предпросмотр роликов и переключение трансляций без перезагрузки страницы
- 🛠️ Постепенная подгрузка контента (кнопка «Показать ещё») для работы с большими подборками
- 📚 Автоматическое отображение постера и состояния загрузки с помощью собственного индикатора
- ✨ Обработка ошибок API с понятными сообщениями и резервными шаблонами
- 🌃 Адаптация под различные сценарии просмотра за счёт собственных шрифтов и адаптивной верстки

## Технологический стек

- **Клиентская часть:** HTML5, CSS3, JavaScript, Fetch API
- **Инфраструктура и инструменты:** Node.js, npm, ESLint, Stylelint, Prettier
- **Архитектура и данные:** REST API, динамическое создание элементов через `<template>`, управление
  состояниями загрузки

## Установка и запуск

1. **Склонировать репозиторий**

   ```bash
   git clone https://github.com/IrinaRyazanskaya/look-out-the-window.git
   cd look-out-the-window
   ```

2. **Установить зависимости (Node.js 22+)**

   ```bash
   npm install
   ```

3. **Запустить локальный сервер**

   ```bash
   npm run serve
   ```

4. **Открыть проект** — по умолчанию `serve` поднимает сайт на http://localhost:3000

## Что реализовано / изучено

- Практика создания одностраничного приложения на чистом JavaScript без сторонних фреймворков
- Организация асинхронных запросов с обработкой успешных и ошибочных ответов API
- Работа с `<template>` для создания однотипных элементов интерфейса
- Реализация пользовательских состояний интерфейса (индикатор загрузки, пустая выдача, ошибка)
- Настройка стиля кода через ESLint, Stylelint и Prettier для единого оформления

## Решённые задачи и технические сложности

- Синхронизация нескольких состояний интерфейса (индикатор загрузки, видео, список карточек) при
  асинхронной загрузке данных
- Ускорение отклика за счёт кэширования состояния карточек и локального переключения видео без
  повторного запроса
- Унификация фильтрации: динамическая сборка строки запроса для разных комбинаций города и времени
  суток
- Повышение удобства использования при отсутствии данных — собственные шаблоны ошибок и мягкий
  запасной сценарий вместо пустого экрана
